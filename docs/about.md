# About NetPulse AI

NetPulse AI is network security software for a single computer. It watches the computer's connections and has an AI model, trained on real attack traffic, check every one, then explains the result in plain words. It runs as a desktop app, a command line and an optional background service on Windows, macOS and Linux.
