<div class="np-flow" markdown>

1. **Submit the request form.**
   Name, e-mail, computer name and operating system; the reason is optional.
2. **Your request is reviewed.**
   Access keys are issued by hand while NetPulse is invite-only.
3. **An individual NetPulse access key is issued.**
   It is sent to the e-mail address you entered. It starts with `np_` and is yours alone.
4. **Enter the key during NetPulse setup.**
   First-run screen → *Your access key* → **Connect**.
5. **Start AI-assisted monitoring.**
   Press **Start protection**. Every connection is now checked by the NetPulse AI service.
