<div class="np-flow" markdown>

1. **Open the [Download page](/netpulse-website/download/).** It always offers the latest version, currently **{{ version }}**.
2. **Pick your system:** the same tab you used the first time.
3. **Stop the background service if you use it:** `netpulse service stop` (administrator / root).
4. **Install the new version over the old one.** Do not uninstall first. On Windows the installer closes NetPulse if it is open.
5. **Your settings, access key and history are kept.** They live in your user folder, not in the program folder.
6. **Open NetPulse again.** The footer of NetPulse Home shows the new version; `netpulse version` shows it for the CLI. Start the service again if you stopped it.
